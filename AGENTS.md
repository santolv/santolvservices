# Project Context: notionobsidiansupercerebro

## Working rule (always apply)

Before starting any task that has a visual reference, or that requires knowing how something works/looks, first search for an available skill that fits that function and USE it (load it with the skill tool and follow its guidance). Do not skip this step. Prefer design/animation/UI skills such as emil-design-eng, apple-design, animate, choreograph, mobile-native, prototype, break-ui, pick-ui-library when relevant.

## Project goal

Build an alternative to Notion + Obsidian that unifies the best of both, with the simplest possible backend. Primary programming language must be Rust; use other languages as little as possible. Backend should be as rudimentary/simple as possible. Visual style should combine Obsidian + Notion (best of each into one).
