# santolvphotos

Galería de fotos y vídeos autohospedada, inspirada en Google Fotos e Immich.

Rust es el lenguaje principal. Antes de incorporar otros lenguajes se consultará
al propietario y se explicará su necesidad.

El trabajo inicial se centra en la interfaz, sin desarrollar todavía el backend.
Consulta el [plan del frontend](frontend/PLAN.md) para conocer tecnologías,
pantallas, fases y criterios de entrega.
