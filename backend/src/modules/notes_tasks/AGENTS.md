# Área Notas y Tareas

Lee `docs/areas/notas-tareas/README.md` y `docs/COLABORACION.md` antes de editar.
Mantén el servicio como un módulo Rust independiente dentro del backend central.
Coordina con Core los permisos y el registro del servicio, y con Compartido si
se necesitan archivos adjuntos. No edites Drive, Fotos ni `frontend/shared/`
desde esta área.
